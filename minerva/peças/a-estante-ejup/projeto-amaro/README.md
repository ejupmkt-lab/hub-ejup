# A Estante EJUP · Projeto Amaro

Quatro stories 1080×1920. `python3 _build/gerar.py --edicao projeto-amaro && python3 _build/render.py`

Ficha: *Projeto Amaro: um resgate histórico da vida e da obra de Amaro
Cavalcanti*. Coordenação: Edilson Pereira Nobre Júnior, Marcelo Navarro
Ribeiro Dantas, Marco Bruno Miranda Clementino e Robson Maia Lins. Editora
Noeses, lançado em 16/12/2025 no STJ. Ligado ao EJUPcast #19 (Marco Bruno).

O trilho vai de 1849 (nascimento de Amaro Cavalcanti, Caicó/RN) a HOJE:
construir, esquecer, resgatar, citar.
