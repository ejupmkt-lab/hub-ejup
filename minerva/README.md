# EJUPMinerva

Repositório de continuidade do trabalho de marca/marketing da EJUP entre dispositivos
(Claude Code no computador ↔ Claude Code no celular).

## Como retomar em uma conversa nova

Anexe (ou peça para o Claude ler) estes dois arquivos, nesta ordem:

1. **`CLAUDE.md`** — o charter da marca: voz, paleta, tipografia, arquétipos, regras não
   negociáveis. Vale como instrução permanente.
2. **`HANDOFF-EJUP.md`** — tudo que foi decidido em conversa e não está no charter: pessoas,
   convidados do EJUPcast, decks já produzidos, armadilhas técnicas do motor de apresentação,
   e o histórico de cada peça de design em andamento.

## O que tem aqui

- `skills/ejup-design/` — cópia da skill de design instalada em `~/.claude/skills/ejup-design/`
  na máquina principal (tokens, fontes Gotham licenciadas, logos, motor de carrossel de
  Instagram). Se for reinstalar num Claude Code novo, copie esta pasta para
  `~/.claude/skills/ejup-design/`.
- `peças/` — entregas finais de design já aprovadas (carrosséis, stories), prontas para
  publicar ou reaproveitar. Ver `peças/README.md`.
