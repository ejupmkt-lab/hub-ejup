# EJUP Plataforma (Área do Aluno) — UI Kit

The student learning platform: navy sidebar shell, dashboard, and a lesson player.

## Screens
- `Sidebar.jsx` — `AppSidebar` — navy fixed nav with progress widget.
- `Dashboard.jsx` — `AppDashboard` — search topbar, "continue" hero card, course-progress grid.
- `Lesson.jsx` — `AppLesson` — video player, content/materials/notes tabs, module lesson list.
- `index.html` — interactive shell: dashboard ⇄ lesson (click "Retomar aula" / a course card).

## Composition
Uses `Button`, `Card`, `Eyebrow`, `Badge`, `Avatar`, `Tabs` from `window.EJUPDesignSystem_063f43`.

## Notes
- Video frame is a navy placeholder (no licensed media).
- Logo is the placeholder wordmark.
