Institutional button — restrained, navy-led; use `gold` for a single high-emphasis CTA only.

```jsx
<Button variant="gold" size="lg">Matricule-se</Button>
<Button variant="primary">Ver programa</Button>
<Button variant="secondary">Saiba mais</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
```

Variants: `primary` (navy), `gold` (accent CTA, has gold glow), `secondary` (outline), `ghost`. Sizes: `sm | md | lg`. Props: `disabled`, `fullWidth`, `iconLeft`, `iconRight`. Keep gold rare — one per view.
